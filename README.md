# Standalone Updater

Prepare offline maintenance packages for Windows 11 x64 computers. The toolkit updates Microsoft Defender security intelligence, Microsoft Edge Stable, and installed Office LTSC Professional Plus 2021 or 2024. It reports missing Windows patches for manual installation.

See the [toolkit guide](Offline_Patching_Toolkit/README.md) to prepare a package on a connected Windows PC and run it on a standalone computer. Microsoft payloads are downloaded during preparation; installers, scan catalogs, prepared packages, and device reports are not included in this repository.
